# Handoff: 사내 링크 대시보드 (ITCONNECT Link Dashboard)

## Overview

사내 구성원이 "그거 주소 뭐였지?"를 슬랙에 묻지 않도록 만드는 팀 공용 즐겨찾기 대시보드입니다.
로그인 없이 누구나 보는 **공개 화면**과, 주소를 직접 입력해야만 도달하는 **관리자 화면**으로 구성됩니다.

실제 운영 데이터 **290개 링크 / 10개 상위 카테고리 / 12개 하위 카테고리**가 이미 들어 있습니다.
(크롬 북마크 내보내기 파일에서 추출 — 파비콘 262개 포함)

## About the Design Files

이 번들의 HTML 파일은 **디자인 레퍼런스**입니다. 의도한 화면과 동작을 보여주는 프로토타입이며,
그대로 배포할 프로덕션 코드가 아닙니다.

작업은 **이 HTML 디자인을 대상 코드베이스의 환경에서 다시 구현하는 것**입니다.
아직 코드베이스가 없다면 아래 권장 스택으로 새로 시작하면 됩니다.

권장 스택 (프로토타입이 이 전제로 설계됨)
- Next.js (App Router) + TypeScript + Tailwind CSS
- Supabase (Postgres + Auth + RLS)
- 폰트: Pretendard (CDN 또는 self-host)

## Fidelity

**High-fidelity (hifi)** 입니다. 색상·타이포·간격·인터랙션이 모두 최종값입니다.
`DESIGN_SPEC.md`의 수치를 그대로 옮기면 화면이 동일하게 재현됩니다.

### 프로토타입 실행 방법
`prototype/` 폴더를 정적 서버로 띄우고 (`npx serve` 등) `링크 대시보드 v2.dc.html`을 엽니다.
`data/` 폴더가 같은 레벨에 있어야 링크와 파비콘이 로드됩니다.
관리자 진입: 상단 프로토타입 주소창에 `link.itconnect.dev/admin` 입력 후 Enter →
`admin@itconnect.dev` / `admin1234`

## Assets

- **파비콘**: 크롬 북마크 내보내기 파일에 base64로 내장돼 있던 것을 개별 PNG(16×16)로 추출했습니다.
  262/290개 보유, 없는 28개는 `none.png`(연회색 사각형)로 대체합니다.
  프로덕션에서는 `bookmarks.favicon_url`에 저장하고, 없으면 `https://www.google.com/s2/favicons?domain=<host>&sz=64` 폴백을 권장합니다.
- **폰트**: Pretendard. CDN `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.css`
- 아이콘: 라이브러리를 쓰지 않습니다. 카드의 눈·핀·연필·휴지통·체크는 **직접 그린 stroke SVG path 5개**가 전부이며 `DESIGN_SPEC.md` 2-1장에 원본 path가 들어 있습니다. 그 외 화살표·닫기 등은 텍스트 문자(`+`, `–`, `×`, `↑↓`, `↵`)입니다.

## 중요한 구현 주의사항

1. **공개 화면 어디에도 관리자 진입 경로가 없어야 합니다.** 헤더·푸터·메뉴·아이콘 전부 포함.
   `/admin`은 주소 직접 입력으로만 도달합니다. 프로토타입 상단의 회색 주소창은 시연용 껍데기이며 제품에는 없습니다.
2. **카테고리를 색으로만 구분하지 않습니다.** 전체가 무채색이고 색은 파비콘에서만 나옵니다(색약 대응).
3. **클릭 기록은 페이지 이동 전에 비동기로 남깁니다.** 어뷰징 방어 규칙은 PRD 6장 참고.
4. 모바일 375px에서 터치 영역 최소 44px을 유지합니다.
5. **홈·카테고리 목록·즐겨찾기가 같은 카드 컴포넌트 하나를 공유합니다.** 화면별로 달라지는 것은 상단 액션 아이콘 구성뿐입니다. 별도의 행 목록 뷰를 만들지 마세요.
6. **즐겨찾기(핀)는 관리자 큐레이션 한 벌입니다.** `bookmarks.is_favorite`·`fav_order`에 저장되어 로그인 여부나 PC와 무관하게 모두에게 같은 목록이 보입니다. 핀과 순서 편집은 관리자에게만 노출하고, 운영 중 섹션에는 핀을 노출하지 않습니다.
7. **공개 화면의 연필·휴지통은 서버가 관리자로 인증한 세션일 때만 렌더합니다.** 클라이언트 플래그로만 숨기지 마세요. 삭제는 반드시 카드 위 확인을 거칩니다.
