# 원티드 AI Championship 2026 데이터 누락 점검

점검 시각: 2026년 10월 8일 08:38 한국 시간. 저장본 수집 시각: 2026년 9월 23일 17:18 한국 시간.

## 결론

현재 공식 공개 목록에 있는 1,389개 과제는 모두 저장본에 포함돼 있다. 과제 ID 기준 누락은 0건이다. 제목·요약은 기존 공개 데이터 정리 규칙을 적용하면 모두 일치하고, 주제 태그·사용 도구·제출 시각도 전부 일치한다.

저장본은 1,391건이며, 현재 공식 목록에 없는 과제는 1368번 ER:NOW – AI 기반 실시간 응급실 추천 서비스와 1607번 Book:in이다. 두 ID의 공식 상세 API는 모두 HTTP 404 / NOT_FOUND를 반환했다. 삭제·숨김 등 정확한 사유는 확인할 수 없다. 두 항목은 과거 수집 기록으로 남아 있으므로, 최신 공개 목록과 비교할 때만 별도로 구분해야 한다.

## 확인 범위와 증거

- 공식 웹 페이지: https://event.wanted.co.kr/ai-championship/2026/projects
- 웹 페이지의 공개 클라이언트가 사용하는 목록 API: https://event.wanted.co.kr/champion-api/api/v1/projects
- 조회 조건: contest_id=1, sort=latest, size=20, 로그인 없음, 검색·주제·도구·본선 전용 필터 없음.
- 1~70페이지 전체 조회. 마지막 페이지 9건, has_next=false.
- API 총 건수 1,389와 실제 수집 건수·고유 ID 수가 모두 일치한다. 모든 페이지의 total 값도 일치한다.
- 저장본: data/wanted-ai-championship-2026.json
- 데이터 정리 규칙: scripts/build-wanted-projects.mjs의 sanitizePublicText와 publicUrl 함수를 그대로 적용.

## 저장하지 않은 항목과 최신 값

1. 상세 설명 전문, 썸네일·이미지, 본선 진출 여부는 페이지용 JSON 스키마에 포함돼 있지 않다. 현재 공식 목록에는 썸네일 1,389건과 본선 진출 과제 20건이 있다. 상세 API를 확인한 1734번 과제에는 475자 상세 설명과 이미지 5개가 있어, 향후 서비스 기능 분석을 하려면 이 자료를 추가 확보할 수 있다. 이는 과제 단위 누락과 별개인 저장 범위의 한계다.
2. 투표 값은 공통 과제 1,389건 중 449건에서 달라졌다. 현재 공식 목록 합계는 16,676표이고, 과거 저장본 전체 1,391건의 합계는 12,804표다. 비교 집단이 다르므로 단순 차이를 동일 집단의 투표 증가량으로 해석하면 안 된다. 공통 1,389건의 과거 합계는 12,792표이며, 두 역사 항목에는 당시 12표가 있었다.
3. 저장본에서 서비스 주소가 비어 있는 893번은 누락이 아니다. 공식 주소를 URL 표준으로 정규화하면 호스트가 0.0.0.0이 되고, 기존 publicUrl 함수가 null로 제거한다. 방문자가 자신의 컴퓨터 주소를 열지 않도록 하는 처리다.

## 분석에 미치는 영향과 권장 조치

- 과제 ID·제목·요약·주제·도구로 과거 제출 아이디어를 분석하는 데 누락 문제는 발견하지 못했다.
- 최신 인기 분석에는 현재 투표 수와 본선 진출 정보를 별도 시점 데이터로 확보하는 편이 적합하다. 기존 9월 23일 수집본의 날짜와 값을 덮어쓰면 과거 비교 기준이 사라진다.
- 상세 기능·차별화·구현 방식 분석에는 상세 설명 전문을 추가로 수집해야 한다. 이미지도 필요에 맞춰 별도로 다룰 수 있다.
- 원본 상세 설명의 테스트 계정·연락처·접근 코드가 공개 데이터로 섞이지 않도록 기존 정리 경계를 유지해야 한다.
