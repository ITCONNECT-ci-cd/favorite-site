## 2-1. 링크 카드 — 모든 공개 화면이 공유하는 단 하나의 카드

홈·카테고리 목록·즐겨찾기 목록이 **전부 같은 카드**를 씁니다. 보이는 액션 아이콘만 화면별로 달라집니다.

### 컨테이너
```
position: relative; overflow: hidden; background:#fff; border:1px solid <bd>; border-radius:10px;
padding:12px(모바일 10px); display:flex; flex-direction:column; gap:6px;
min-height:126px(모바일 104px); box-shadow:0 1px 2px rgba(20,21,22,.04);
transition: transform .22s cubic-bezier(.22,.9,.28,1), box-shadow .22s ease, border-color .22s ease;
```
- `<bd>` 기본 `#dcd7cf` / 즐겨찾기에 담긴 카드 `#cfc7b8` / 체크된 카드 `#141516`
- 호버: `border-color:#141516; transform:scale(1.05); box-shadow:0 10px 26px rgba(20,21,22,.14); z-index:5`
- 카드 전체가 아니라 **파비콘과 본문 블록만 열기 클릭 영역**입니다. 액션 아이콘 클릭이 새 탭을 열지 않게 하기 위해서입니다.

### 상단 줄 (min-height 32px, `display:flex; align-items:flex-start; gap:4px`)
- 왼쪽: 파비콘 타일 32px — 흰 배경 + 1px `#e3dfd9` + 라운드 9px + 배경이미지 19px 중앙
- 오른쪽(`margin-left:auto`, gap 1px, `flex-wrap:wrap; justify-content:flex-end; min-width:0`): 액션 버튼 21×21px, 라운드 6px, 호버 배경 `#efedE8`
  아이콘 4개 최대 폭 = 21×4 + 1×3 = 87px. 파비콘 32px + gap 4px을 더해도 123px로, 카드 안쪽 폭(158−24 = 134px) 안에 들어갑니다.
  그래도 모자라면 줄바꿈되며, 카드의 `overflow:hidden`이 옆 카드 침범과 가로 스크롤 발생을 막습니다.

| 순서 | 아이콘 | 노출 조건 | 꺼짐 | 켜짐 |
|---|---|---|---|---|
| 1 | 체크 | 카테고리·즐겨찾기 목록 화면만 | `#c9c5be` | 배경 `#141516` + 흰 체크 |
| 2 | 핀 | **홈의 매일·운영 중 섹션을 제외한 모든 카드** | `#b5b1aa`, `fill:none` | `#141516` + 배경 `#e4e0d8` + `fill:currentColor` |
| 3 | 연필 | 관리자 로그인 상태만 | `#8b877f` | 호버 `#141516` |
| 4 | 휴지통 | 관리자 로그인 상태만 | `#8b877f` | 호버 `#a8443a` + 배경 `#f4e8e6` |

아이콘은 12px SVG, `fill:none; stroke:currentColor; stroke-linecap:round; stroke-linejoin:round`. 아이콘 라이브러리 없이 아래 path를 그대로 씁니다.

```html
<!-- 눈 (stroke-width 2) -->
<path d="M2 12s3.6-6.5 10-6.5S22 12 22 12s-3.6 6.5-10 6.5S2 12 2 12z"/><circle cx="12" cy="12" r="2.6"/>
<!-- 핀 (stroke-width 1.7) -->
<path d="M9.4 3h5.2l-.8 5.6 3.2 3.1v1.7H6.9v-1.7l3.3-3.1L9.4 3z"/><path d="M12 13.4V21"/>
<!-- 연필 (stroke-width 1.8) -->
<path d="M4 20.5h4L20 8.5l-4-4L4 16.5v4z"/><path d="M14.5 6l4 4"/>
<!-- 휴지통 (stroke-width 1.8) -->
<path d="M4 6.5h16"/><path d="M9 6.5V4h6v2.5"/><path d="M6.5 6.5l1 13.5h9l1-13.5"/>
<!-- 체크 (stroke-width 2.6) -->
<path d="M4.5 12.5l5 5 10-11"/>
```

### 본문 블록 (`margin-top:auto`, 클릭 시 새 탭 열기)
- 이름 13.5px/600 (모바일 13px), `line-height:1.3`, `letter-spacing:-0.01em`, 2줄까지(`max-height:2.6em; overflow:hidden`)
- 설명 12px `#6d6a65`, `line-height:1.4`, 2줄까지, `margin-top:4px`

### 하단 줄 (`margin-top:5px`, `display:flex; align-items:center; gap:8px`)
- 왼쪽: 주소 10.5px `#a5a29c`, 1줄 말줄임
- 오른쪽: **눈 아이콘 12px + 클릭 수** 11px/600 `#8b877f`, gap 4px. **0회도 `0`으로 표기합니다**

### 인라인 편집 (연필 클릭, 관리자 전용)
본문·하단 줄을 입력 폼으로 교체합니다. 카드 밖으로 나가는 모달은 쓰지 않습니다.
- 이름 입력 높이 30px, 테두리 1.5px `#141516`, 12.5px/600
- 설명 입력 높이 30px, 테두리 1px `#ddd8d1`, 12px
- 저장(검은 버튼, `flex:1`, 28px) / 취소(흰 버튼) · `Enter` 저장, `Esc` 취소

### 삭제 확인 (휴지통 클릭, 관리자 전용)
카드 위에 `position:absolute; inset:0` 오버레이 — 배경 `rgba(251,250,248,.97)`, 라운드 10px, `z-index:6`
"이 링크를 삭제할까요" 12px/600 + `삭제`(배경 `#a8443a`, 흰 글자) / `취소`(흰 버튼)

## 3. 홈 (공개)

### 섹션 헤더 (공통 형태)
제목 13.5px/700 + 보조문 11.5px `#9a9791` + 우측 검은 버튼 "N개 한 번에 열기" (높이 30px, 12px/600)

| 섹션 | 보조문 | 특이사항 |
|---|---|---|
| 내 즐겨찾기 | `핀으로 직접 담은 N개 · 이 브라우저에만 저장됩니다` | 카드의 핀이 켜진 상태로 보이고, 다시 누르면 빠집니다. 0개면 열기 버튼 없이 안내 박스만 |
| 매일 사용하는 사이트 | `직접 고정한 12개 · 자리가 바뀌지 않습니다` | **카드에 핀을 노출하지 않습니다** (관리자 영역) |
| 현재 운영 중인 사이트 | `회사가 직접 운영하는 서비스 16개` | "전체 보기" 텍스트 링크가 열기 버튼 왼쪽에 붙습니다. 핀 노출 없음 |

카드 명세는 **2-1장** 그대로입니다. 그리드 열 수는 브레이크포인트 표 참조.

### 빈 즐겨찾기 안내
점선 테두리 `#d8d3cb`, 배경 `#f3f1ed`, 라운드 10px, 패딩 16px, 11.5px `#6d6a65`
`다른 화면에서 카드 오른쪽 위의 핀을 누르면 이 자리에 모입니다. 매일 사용하는 사이트와 달리 내가 직접 담고 빼는 목록입니다.`

### 하단 안내
`나머지 262개는 왼쪽 사이드바에서 분류별로 들어갑니다. 홈에는 즐겨찾기와 매일 사용하는 사이트, 현재 운영 중인 사이트를 둡니다.`
점선 테두리 `#d8d3cb`, 배경 `#f3f1ed`, 라운드 9px, 11.5px `#6d6a65`

## 4. 카테고리 목록 · 내 즐겨찾기 (공개)

- 제목 20px/700 + 개수 12px `#9a9791` + 설명 12.5px `#6d6a65`
- 하위가 있으면 탭 칩 줄: `전체`(개수) + 하위별. 선택 시 배경 `#141516`/흰 글자, 아니면 흰 배경 + `#ddd8d1`
- 툴바: `전체 N개 열기`(검은 버튼) / `선택 N개 열기`(흰 버튼) / `선택 해제` / 우측 안내문(narrow에서 숨김)
- **본문은 행 목록이 아니라 홈과 똑같은 카드 그리드입니다** (2-1장). 이 화면의 카드만 체크 아이콘을 함께 노출합니다.
- 선택된 카드는 테두리가 `#141516`으로 바뀌어 한눈에 구분됩니다.
- 비어 있으면 점선 안내 박스: 즐겨찾기는 `아직 담은 즐겨찾기가 없습니다. 목록에서 카드의 핀을 눌러보세요.` / 그 외 `이 분류에 링크가 없습니다.`

## 8. 상태 (프로토타입 기준)

| 상태 | 설명 |
|---|---|
| `route` | `home` / `cat` / `login` / `admin` |
| `key`, `sub` | 선택된 상위·하위 카테고리 |
| `links` | 링크 배열 (id, title, url, host, desc, group, sub, tags, pinned, order, added) |
| `clicks`, `log` | 링크별 누적 클릭 / 클릭 로그(최근 600건) |
| `descs`, `titles`, `groups`, `subsMap` | 수정된 설명 / 수정된 이름 / 카테고리 순서 / 하위 카테고리 |
| `favs` | 개인 즐겨찾기 (`{[id]: true}`) — 방문자별로 다릅니다 |
| `deleted` | 관리자가 카드에서 지운 링크 id |
| `editId`, `editTitle`, `editDesc`, `confirmId` | 카드 인라인 편집 / 삭제 확인 대상 |
| `authed` | 관리자 로그인 여부. 공개 화면의 연필·휴지통 노출을 결정합니다 |
| `palette`, `q`, `sel`, `ai`, `aiResults` | 검색 팔레트 상태 |
| `adminTab`, `catSel`, `catQ`, `subFilter`, `sortMode` | 관리자 화면 상태 |
| `period`, `staleDays` | 통계 기간 / 방치 판정 기준 |
| `w` | 뷰포트 폭 (반응형 분기) |

프로토타입은 `localStorage['linkdash-v2']`에 `clicks / log / descs / titles / deleted / favs / groups / subsMap`을 저장합니다.
프로덕션에서는 `favs`를 제외한 전부를 Supabase로 옮깁니다. `favs`는 방문자 개인의 것이므로 계정이 생기기 전까지 브라우저에 남깁니다.
