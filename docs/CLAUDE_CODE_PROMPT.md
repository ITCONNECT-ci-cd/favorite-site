# Claude Code 시작 프롬프트

아래 내용을 그대로 붙여넣고 시작하면 됩니다. 이 폴더를 프로젝트 루트에 두거나, 내용을 새 저장소로 복사한 뒤 실행하세요.

---

이 폴더는 사내 링크 대시보드의 **디자인 핸드오프 번들**입니다. 프로덕션 코드로 다시 구현해 주세요.

**먼저 읽을 것 (순서대로)**
1. `README.md` — 무엇을 만드는지, 하지 말아야 할 것
2. `PRD.md` — 기능 목록, 데이터 모델, 개발 단계
3. `DESIGN_SPEC.md` — 색·타이포·간격·컴포넌트 수치. **2-1장(링크 카드)이 이 제품의 핵심**입니다
4. `screenshots/` — 위 명세가 실제로 어떻게 보이는지
5. `prototype/링크 대시보드 v2.dc.html` — 동작하는 프로토타입. 정적 서버로 띄워 직접 눌러 보세요

**스택**
Next.js(App Router) + TypeScript + Tailwind + Supabase(Postgres/Auth/RLS). 폰트는 Pretendard.

**작업 순서**
`PRD.md` 9장의 5단계를 그대로 따릅니다. 1단계(공개 화면 읽기 전용 + 클릭 집계)를 먼저 끝내고 확인받은 뒤 다음으로 갑니다.

**데이터**
`data/links.json` 290건이 실제 시드입니다. `PRD.md` 7장의 매핑 표대로 넣으세요.
`data/icons/<링크 id>.png`가 파비콘 262개입니다. Supabase Storage에 올리고 `bookmarks.favicon_url`에 연결합니다.

**반드시 지킬 것**
- 카드 컴포넌트는 **하나**만 만듭니다. 홈·카테고리 목록·즐겨찾기가 전부 같은 카드를 씁니다. 화면별로 다른 건 상단 액션 아이콘 구성뿐입니다.
- 공개 화면 어디에도 관리자 진입 링크를 두지 않습니다. `/admin`은 주소 직접 입력으로만 도달합니다.
- 연필·휴지통은 **서버가 관리자 세션으로 확인했을 때만** 렌더합니다. 클라이언트 조건부 숨김만으로 처리하지 않습니다.
- 개인 즐겨찾기(핀)는 방문자 브라우저 저장이고, 매일 고정(최대 12)은 관리자가 정하는 전사 공통입니다. 두 개를 섞지 마세요.
- 색·간격·폰트 크기는 `DESIGN_SPEC.md`의 값을 그대로 씁니다. 임의로 바꾸지 마세요.
- 히어로·일러스트·그라데이션·장식 아이콘 금지. 색은 파비콘에서만 나옵니다.

**프로토타입에서 흉내만 낸 부분 (진짜 구현이 필요)**
- AI 의미 검색: 지금은 의도 사전 10종 + 토큰 겹침입니다. pgvector 임베딩 또는 LLM 호출로 교체합니다
- 클릭 집계: 지금은 localStorage입니다. `clicks` 테이블 + 어뷰징 방어(`PRD.md` 6장)로 교체합니다
- 로그인: 하드코딩된 계정입니다. Supabase Auth로 교체합니다
- "한 번에 열기": 크롬 탭 그룹 묶기는 웹 권한 밖입니다. 확장 없이는 여러 탭 열기까지만 됩니다
